    The question

    Can a fund's Morningstar numbers at the end of one year tell us if it will beat the Nifty 50 by 3 points or more the next year? Excess always means fund return minus Nifty 50 price return. Each parameter year is paired with the following year's return.

    The data

    • Source: Parameter data updated-Dec 25(1).xlsx for parameters and returns, and Book3.xlsx for the fund list and categories.
    • Size: 396 funds, 3,943 fund-years and 101 parameters, for returns 2006–2025.
    • Funds with short histories are kept and counted for the years they exist.
    • Monthly files: not used, because each block was calculated over one month and most parameters came out blank.

    Period test, step by step

    The periods are return years. Testing 2024–2025 means predicting the 2024 and 2025 returns from the 2023 and 2024 parameters. The two periods cannot overlap, so nothing from testing leaks into the analysis.

    1. Statistics, analysis period only. In each year, funds are compared within the group. The parameter is standardised, capped at ±3 SD, and next-year excess is regressed on it. The slope is the points of excess per 1 SD. This is the Fama-MacBeth method.
    2. Significance. The yearly slopes are averaged and given a t-statistic with a Newey-West standard error, then a p-value.
    3. Which parameters get tested. Robust first: p ≤ 0.05 and the same sign in both halves of the period. If none, those with p ≤ 0.05. If still none, the five strongest by t-statistic, clearly labelled.
    4. Unique. Versions of one measure count once (Alpha and Alpha (Annualized)). A parameter moving with a stronger one (rank correlation above 0.80) is dropped.
    5. Five ranges. In each analysis year funds are split into five equal groups by the parameter, Q1 lowest to Q5 highest. Each fifth's next-year excess is averaged per year, then across years.
    6. Prediction. In each testing year a fund is placed in its fifth for that year. Its predicted excess is that fifth's analysis average.
    7. Compare with what happened. The hit ratios, deviation and baskets below.

    Reading the results

    • 3%+ call: right when "predicted ≥ 3" and "actual ≥ 3" agree. A correct "won't beat" counts as a hit. This is the main test.
    • Excess hit ratio: only funds predicted at +0.01% or more are counted. It's a hit if the fund's actual excess is above 0. Funds predicted below +0.01% are left out, so check how many were counted.
    • Actual ≥ predicted: right when the fund did at least as well as predicted. Treat this one with care, because low predictions pass it easily.
    • Deviation is actual minus predicted, and positive means funds did better than predicted.
    • Feasible means the 3%+ hit ratio is above the cut, there are at least 30 predictions, and more calls are right than if every fund simply got the group's analysis average. So a high hit ratio can still be "no" when the parameter adds nothing to that average.
    • Baskets group predictions by predicted excess. If predictions were good, each basket's actual average would land inside its own range.

    Previous parameters

    The nine parameters from the earlier correlation study run through the same steps on the same periods. Their statistics table shows how they score in the analysis period. The earlier correlations pooled all years together, so much of that signal reflects which years favoured risky funds, not which funds were better within a year.

    Common traps

    • Every fund gets the same call. If all five fifths land on the same side of 3%, every fund gets the same call and the parameter adds nothing. If "Called 3%+" is 0 or equals Predictions, this is what happened.
    • Short analysis periods. With 4 years there are only 4 yearly slopes, so a p-value can look strong by chance. The standard analysis needs 8+ years. Treat shorter periods as exploratory.
    • Trying many periods. Run enough combinations and one will pass by luck. A result counts only if it holds across several periods.
    • Small categories. A year needs at least 10 funds to form fifths, so some categories have few or no predictions.

    Analysis only

    Set Run to Analysis only to skip testing. You get t, p and q for all 101 parameters in the chosen years, plus the nine previous parameters, with no predictions.

    Indicator tests

    Each of the 101 indicators is tested against two outcomes: next-year excess return, and whether the fund beat the Nifty 50 by 3 points (1 or 0). This is association only, with no predictions and no hit ratio.

    • Direction: positive means higher indicator values went with better outcomes.
    • Effect size: the average yearly slope per 1 SD of the indicator. For the 3-point target it is a change in probability, so +5 means a 5-point higher chance.
    • 95% CI: effect ± t critical × Newey-West standard error. If it crosses 0, the result isn't significant at 5%.
    • p-value: from the t distribution with years − 1 degrees of freedom.
    • Keep in mind: no correction is made for testing many indicators, so at p ≤ 0.05 about 5 in every 100 tests can look significant by luck. Many indicators are also near-copies, so check Parameter correlation.

    Linear regression

    Ordinary least squares with next-year excess return as the outcome, over all fund-years in the period. Rows missing any chosen parameter are dropped.

    • Prediction for 2026: the multiple regression's formula applied to each fund's 2025 parameter values. It uses the model and funds you select. The 95% range is the prediction ± about 2 × the residual error, so it allows for year-to-year market swings. With Year effects on, the starting value is the average year.
    • Clustered by year (default): funds in one year share the market's move, so they aren't independent. This setting allows for that, with years − 1 degrees of freedom. Classic OLS treats every fund-year as independent, which gives much larger t-values.
    • Year effects: removes each year's average, so the model compares funds within a year, like Indicator tests.
    • Top 20 heatmap: rank correlations between the 20 parameters with the smallest p when tested one at a time. Values near ±1 mean they carry largely the same information.
    • VIF: how much a parameter overlaps with the others in the model. Above 10 means its coefficient is unreliable.

    Parameter correlation

    This shows how closely parameters move together across funds. All fund-years in the chosen period are ranked on each parameter, and each pair's ranks are correlated, the same measure used in the Unique step. +1 means they rank funds the same way and −1 means the opposite. It doesn't show whether a parameter predicts returns. Many pairs are near ±1 because they are versions of one measure, such as Alpha and Alpha (Annualized). Use "Hide versions of one measure" to see the pairs that aren't. Note that Average Drawdown and Max Drawdown are identical in the source data, so they always show +1.

    Years with data

    Period test can require a parameter to have data for a minimum share of the analysis years and of the testing years. An analysis year counts if the parameter has a yearly slope, and a testing year counts if funds can be split into fifths, which needs at least 10 funds. Parameters that fall short are left out of the shortlist and the tables. The nine previous parameters always stay listed and show "Too little data". In the tables, 7/15 · 1/3 means 7 of 15 analysis years and 1 of 3 testing years.

    Excluding 2008 and 2009

    The switch at the top removes return years 2008 and 2009, and the 2007 and 2008 parameters paired with them, from every tab. The 2009 parameters stay, because they're paired with 2010 returns. Hatched years in the timeline are left out. Period lengths count only the years still in use.

    The other tabs

    • Testing & prediction uses the full history. It walks forward year by year from 2020, so each test year learns from all earlier years, then predicts 2026 from feasible parameters.
    • Previous parameters is the same walk-forward test for the nine parameters.
    • Statistical analysis runs the statistics above over all years, for every group.
